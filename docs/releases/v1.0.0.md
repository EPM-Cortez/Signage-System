# School Signage Publisher 1.0.0

Initial production build of the self-hosted PowerPoint-to-browser signage system.

- Teacher uploads, permitted screen groups, durable conversion jobs, scheduling, display pairing/revocation, and immutable packages cached for offline playback.
- Text/chart/layout renderer fixes with bundled open-licensed fonts; native embedded MP4/WebM playback to completion and validated online YouTube embeds.
- Active Directory LDAPS username/password sign-in, an admin-only directory test, locally managed staff roles, account disabling, and teacher-specific screen-group permissions. OIDC remains supported.
- Windows x64 Release package, dependency inventories, SHA-256 checksum, installation guide, and tagged GitHub release automation.

Install the ASP.NET Core 10.0.10+ runtime and Node.js 22.23.1+ (22.x), then follow `INSTALL.md` in the ZIP. Authentication and HTTPS must be configured for your school. No local data, school presentations, credentials, or development sign-in configuration are included.

The build runs .NET unit/integration tests, converter/player tests, browser end-to-end tests, and a packaged Production-mode smoke test. Real school AD/HTTPS/network integration and the private presentation corpus still require deployment-site validation. Exact PowerPoint animation/transition fidelity and every possible video codec are not supported; see the compatibility guide.
