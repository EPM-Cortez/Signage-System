# Private renderer corpus checklist

Do not commit school or personal data. For each representative deck, record owner/permission, aspect ratio, fonts, renderer version, result, and screenshots in the organisation's approved private location.

- [ ] Text wrapping and fallback fonts
- [ ] Image crop and transparency
- [ ] SmartArt
- [ ] Common and unusual charts
- [ ] Tables
- [ ] Grouped objects
- [ ] Master/layout inheritance
- [ ] 4:3 and custom aspect ratio
- [ ] Embedded media warning
- [ ] Animation-heavy deck flattening
- [ ] Hidden slides
- [ ] Automatic slide timing
- [ ] External relationships
