# Install School Signage

This download is a **Windows x64, framework-dependent production build**. Install the ASP.NET Core Runtime **10.0.10 or a newer 10.0 patch** and Node.js **22.23.1 or a newer 22.x patch** first.

Follow the [production quickstart](docs/production-quickstart.md): configure `app/appsettings.Production.json` from the supplied sample, set up AD LDAPS or OIDC and HTTPS, apply migrations, and then install the service. No school credentials or demo accounts are included. Review [the release checklist](docs/release-checklist.md) before rollout.
